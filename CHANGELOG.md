# Changelog

Changes that matter to players, newest first. Versions follow [semantic versioning](https://semver.org/).

## 0.1.1

- Shorter install notes, with Fightcade's usual folder and how to uninstall.

## 0.1.0

The first release, for Street Fighter III: 3rd Strike on Fightcade.

- Grades special moves and super arts for all 20 characters: each input against the window the game allows, and what went wrong when a move did not come out.
- Names cancels from a normal that came too early or too late, or from a normal that whiffed.
- Names moves the game refused: no meter, a projectile still on screen, or a move that needs the super art running.
- Times dashes, the throw or button right after a dash, parries, and Chun-Li's Hyakuretsukyaku.
- A target menu, a success rate for the target, and recent attempts under the card.
