# Roadmap

- P2 support, to grade from either side of a netplay or training session.
- A training journal: progress per move over days and weeks, built from the attempt log.
- Red parry detail. The card says when a parry needed the shorter red window, but not yet whether the attack counted as a normal (3 frames) or a special (2 frames).
- More actions before a press: landing from a jump, the end of blockstun (reversals) and waking up. Each needs its routine and first actionable frame measured; the follow-up tracker and the card already take any action.
- A move cheatsheet on a hotkey: the current character's specials and selected super art, with each step's window and the optional last directions, drawn with the card's icons. The command tables already hold everything it needs.
- A pinned FBNeo build under Wine in the flake, to try the script without Fightcade. FBNeo's Lua only exists in its Windows build, and its command line takes a game or a script but not both, so this would be a manual check rather than an automated one.
- Other games, through the [porting](porting.md) interfaces.
